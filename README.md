# 图灵数盟 · 数据专家体系（Data Experts）

**作者**：图灵数盟（图灵数盟（深圳）数字产业有限公司）｜**官网**：https://www.turingtech.net.cn｜**联系**：public@turingtech.net.cn

面向数据要素与数据资产领域的 **52 位专家 Agent** 与 **9 个专家团**，
以标准 Agent Skills（`SKILL.md`）格式开放。每位专家包含岗位知识底座、政策与标准依据、
核心模型、标准作业流程 SOP、交付物清单与质量校验清单。

## 快速使用

```bash
# 方式一：克隆后放入你的 Agent 技能目录
git clone https://github.com/<your-org>/turing-data-experts.git
cp -r turing-data-experts/skills/data-asset-capitalization-expert ~/.claude/skills/

# 方式二：按平台「上传技能」入口，选择 skills/<expert-id>/ 打包的 ZIP
```
